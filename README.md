# 📖 문해보감 (Munhaebogam)

**문해보감**은 체계적인 문해력 향상과 어휘력 강화를 돕는 프리미엄 교육 플랫폼입니다. 사용자 맞춤형 학습 콘텐츠와 몰입감 있는 인터페이스를 제공하여 독해력 향상을 이끕니다.

## ✨ 핵심 기능 (Key Features)
- **단계별 문해력 진단**: AI 기반 어휘 및 독해력 테스트 제공.
- **맞춤형 학습 파이프라인**: 학습자 수준에 맞춘 데일리 리딩 퀘스트.
- **스마트 대시보드**: 학습 성취도 및 진행 상황 시각화.

## 💻 Tech Stack
- **Frontend**: React (TypeScript) + Vite
- **Styling**: Tailwind CSS (Modern Educational UI)
- **State Management**: Zustand / Context API

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/manodist/munhaebogam.git

# Install dependencies
npm install

# Start the development server
npm run dev
```
