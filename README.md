# 📖 문해보감 (Munhaebogam)

**문해보감**은 체계적인 문해력 향상과 어휘력 강화를 돕는 프리미엄 교육 플랫폼입니다. 사용자 맞춤형 학습 콘텐츠와 몰입감 있는 인터페이스를 제공하여 독해력 향상을 이끕니다.
**Munhaebogam** is a premium educational platform designed to systematically improve literacy and vocabulary. It guides users towards better reading comprehension by providing personalized learning content and an immersive interface.

## ✨ 핵심 기능 (Key Features)
- **단계별 문해력 진단 (Step-by-step Literacy Assessment)**: AI 기반 어휘 및 독해력 테스트 제공.
- **맞춤형 학습 파이프라인 (Personalized Learning Pipeline)**: 학습자 수준에 맞춘 데일리 리딩 퀘스트 (Daily reading quests tailored to the learner's level).
- **스마트 대시보드 (Smart Dashboard)**: 학습 성취도 및 진행 상황 시각화 (Visualizing learning achievements and progress).

## 💻 기술 스택 (Tech Stack)
- **프론트엔드 (Frontend)**: React (TypeScript) + Vite
- **스타일링 (Styling)**: Tailwind CSS (Modern Educational UI)
- **상태 관리 (State Management)**: Zustand / Context API

## 🚀 빠른 시작 (Getting Started)

```bash
# Clone the repository
git clone https://github.com/manodist/munhaebogam.git

# Install dependencies
npm install

# Start the development server
npm run dev
```
